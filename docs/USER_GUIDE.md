# 使用指南

## 1. 安裝與首次啟動

APP 支援 Android 8.0 以上裝置。安裝完成後可先瀏覽主畫面，但查詢真實資料前必須設定中央氣象署授權碼；環境部 API Key 則用於空氣品質功能。

## 2. 申請 API 授權碼

### 中央氣象署 CWA

1. 開啟[中央氣象署氣象資料開放平台](https://opendata.cwa.gov.tw/index)。
2. 註冊並登入。
3. 取得 API 授權碼。
4. 回到 APP 設定頁，貼入「中央氣象署 CWA」欄位。
5. 按「連線測試」，看到「可用」後按「儲存設定」。

### 環境部 MOENV

1. 開啟[環境部 API 申請頁](https://data.moenv.gov.tw/api-term)。
2. 接受服務條款、註冊並取得 API Key。
3. 回到 APP 設定頁，貼入「環境部 MOENV」欄位。
4. 按「連線測試」，看到「可用」後按「儲存設定」。

兩個 API 區塊皆提供眼睛按鈕顯示或隱藏內容，以及清除按鈕。授權碼內容變更後，原本的測試成功狀態會被重設。

## 3. 查看天氣

主畫面提供：

- 目前位置名稱
- 天氣圖案與溫度
- 天氣描述與體感溫度
- 濕度、降雨機率及風況
- AQI、PM2.5 與空品測站
- 未來七日預報
- 資料更新時間與來源

按右上角更新按鈕可重新取得資料。

## 4. 選擇地點

1. 點擊主畫面的地點按鈕。
2. 在「地點與收藏」畫面點擊縣市。
3. 使用搜尋欄或捲動清單選取縣市。
4. 點擊鄉鎮市區並選取地點。
5. 按「查看天氣」返回主畫面。

選擇頁左上角與手機系統返回鍵都會回到「地點與收藏」畫面，不會直接離開整個流程。

## 5. 使用 GPS

1. 點擊主畫面地點右側的定位圖示。
2. 同意定位權限。
3. APP 取得最近位置並透過 Android Geocoder 辨識行政區。
4. 國碼不是 `TW` 或行政區不在支援清單時，顯示不支援訊息。

APP 不會在背景持續定位。拒絕權限後仍可手動選擇地點。

## 6. 管理收藏

在「地點與收藏」畫面：

- 按「加入收藏」保存目前選擇。
- 按收藏項目即可查看該地天氣。
- 按向上或向下箭頭調整順序。
- 按刪除圖示移除收藏。

收藏順序會保存在裝置並於重新啟動後保留。

## 7. 顯示模式

設定頁提供：

- 系統：跟隨 Android 系統深色模式。
- 淺色：固定使用粉彩淺色主題。
- 深色：固定使用深色主題。

選擇後立即生效，狀態列與系統 Navigation Bar 也會同步調整。

## 8. 常見問題

### 無法取得 GPS 位置

確認定位服務已開啟、APP 已取得定位權限，並確認裝置提供 Geocoder 服務。仍無法辨識時請使用手動選擇。

### API 授權碼測試失敗

- 確認沒有多餘空白或換行。
- 確認金鑰沒有過期。
- 確認網路可用。
- 確認當日 API 配額尚未用完。
- CWA 與 MOENV 的金鑰不能互換。

### 空氣品質沒有顯示

確認 MOENV API Key 已設定且測試成功。若同縣市沒有有效測站資料，空品區塊可能不顯示。

### 後半週降雨機率顯示 `--`

代表 CWA 資料集未提供該時段欄位。APP 不會使用第三方資料自行補值。
