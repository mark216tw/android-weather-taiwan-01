# 隱私說明

更新日期：2026-09-23

## 資料處理原則

「台灣天氣」不使用自有後端，也不建立使用者帳號。天氣及空品請求由使用者裝置直接送往中央氣象署與環境部開放資料平台。

## API 授權碼

- CWA 與 MOENV 授權碼由使用者自行申請及輸入。
- 授權碼使用 Android Keystore 管理的 AES-GCM 金鑰加密後，保存在 APP 私有 DataStore。
- APP 不會將授權碼傳送到資料來源以外的服務。
- APP 不會將完整授權碼寫入 Log。
- 使用者可在設定頁清除欄位並儲存，以刪除本機保存內容。

## 定位資料

- 定位只在使用者主動按下定位按鈕後使用。
- APP 不要求背景定位。
- 座標用於 Android Geocoder 行政區辨識，以及決定要查詢的台灣地點。
- APP 不會將位置傳送到自有伺服器，也不建立位置歷史紀錄。
- 使用者可拒絕定位並改用手動地點選擇。

## 本機保存資料

APP 會在裝置保存：

- 加密後的 API 授權碼
- 收藏地點及順序
- 最近選擇的地點

解除安裝 APP 或清除 APP 資料通常會刪除上述內容；實際行為仍受 Android 備份與裝置設定影響。

## 第三方服務

APP 使用以下服務：

- 中央氣象署氣象資料開放平台
- 環境部環境資料開放平台
- Google Play Services Location（取得裝置位置）
- Android Geocoder（解析行政區）

各服務可能依其隱私政策及服務條款處理請求資訊，例如 IP 位址、API Key 或必要的技術資料。

## 資料刪除

使用者可：

- 在設定頁清空 API Key 並儲存。
- 在地點與收藏頁刪除收藏。
- 透過 Android 系統設定清除 APP 資料。
- 解除安裝 APP。
