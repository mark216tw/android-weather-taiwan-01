# 下一階段優化建議

本文件整理「台灣天氣」後續開發方向。建議先改善資料準確度、效能與穩定性，再逐步增加產品功能與正式發行能力。

## 第一優先：資料與效能

### 1. 天氣快取與離線顯示

- 保存最近一次成功取得的天氣及空品資料。
- 無網路時顯示上次資料及更新時間，而不是只顯示整頁錯誤。
- 預報建議快取 30–60 分鐘。
- 即時觀測建議快取 10–15 分鐘。
- 空氣品質建議快取 30 分鐘。

### 2. 平行查詢 API

- 平行查詢 CWA 預報、即時觀測與 MOENV 空品。
- 減少主畫面等待時間。
- 合併相同地點的重複請求。
- 防止使用者連續點擊更新造成大量 API 呼叫。

### 3. 改善測站選擇

- 解析氣象及空品測站座標。
- 使用 GPS 或鄉鎮中心座標計算最近測站。
- 不再只使用同縣市第一筆有效測站。
- 顯示測站名稱、資料時間及與目標位置的距離。

### 4. GPS 定位可靠性

- 檢查 `lastLocation` 的資料時間及精確度。
- 位置過期或不存在時，主動要求一次新的位置更新。
- 改用新版非同步 Geocoder API。
- 可加入台灣行政區邊界 GeoJSON，改善縣市交界與離島判斷。

## 第二優先：產品體驗

### 5. 逐時天氣預報

- 增加未來 24–48 小時預報。
- 顯示溫度、降雨機率及天氣趨勢。
- 使用水平時間軸或折線圖呈現。
- 清楚區分觀測值與預報值。

### 6. 氣象警特報

- 串接中央氣象署警特報資料。
- 顯示豪雨、颱風、強風、高溫及低溫等警示。
- 提供影響地區、發布時間及詳細內容。
- 後續可加入警特報通知。

### 7. 空氣品質健康建議

- 依 AQI 等級提供戶外活動建議。
- 提供敏感族群及口罩使用提醒。
- 使用官方分級顏色並搭配文字，避免只依顏色傳達狀態。

### 8. 收藏操作優化

- 可評估加入拖曳排序。
- 支援設定預設地點。
- 收藏列表直接顯示簡短溫度與天氣。
- 防止同一地點重複收藏。

### 9. 首頁資訊層級

- 增加今日天氣摘要，例如「午後降雨機率高，記得帶傘」。
- 未設定 MOENV Key 時顯示空品設定引導。
- API 部分失敗時顯示區塊級錯誤與重試，不影響其他成功資料。

## 第三優先：工程品質

### 10. 拆分 Compose 畫面

- 將 `AppScreen.kt` 拆分成主畫面、地點、設定與共用元件。
- 改用 Navigation Compose 管理導覽及返回堆疊。
- 支援程序重建後的畫面狀態恢復。

### 11. 字串資源與國際化

- 將 Kotlin 中的繁體中文移至 `strings.xml`。
- 集中管理日期、時間及單位格式。
- 為後續英文或其他語言介面預留結構。

### 12. 增加測試

- CWA JSON 解析測試。
- API 錯誤碼及缺值測試。
- ViewModel 狀態測試。
- 使用 MockWebServer 建立網路契約測試。
- Compose UI、主題切換、返回流程及地點搜尋測試。

### 13. 無障礙

- 測試系統字體放大至 200%。
- 增加 TalkBack 語意及按鈕狀態描述。
- 檢查淺色及深色模式文字對比。
- 避免天氣狀態只依 Emoji 或顏色呈現。

### 14. 正式發行流程

- 建立正式 Release signing，不使用 Debug Key。
- 加入 GitHub Actions，自動執行測試、Lint 與建置。
- 建立版本 Tag、GitHub Release 及 APK SHA-256。
- 加入 Dependabot 與 CodeQL。
- 準備 Google Play 隱私政策與 Data Safety 資料。

## 第四優先：進階功能

- 桌面小工具。
- 每日天氣通知。
- 降雨及警特報通知。
- 雷達回波與雨量趨勢。
- 穿搭、紫外線與戶外活動建議。
- 平板及橫向畫面版型。

## 建議開發順序

1. 快取與離線模式。
2. API 平行請求及最近測站計算。
3. 氣象警特報與逐時預報。
4. Navigation Compose、檔案拆分及字串資源化。
5. 完整測試及 GitHub Actions。
6. 正式簽章與發布流程。

- 離線資料顯示。

- 最近氣象與空品測站計算。

- 中央氣象署警特報。
